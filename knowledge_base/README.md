# Knowledge Base

This directory will hold structured knowledge documents for the RAG (Retrieval-Augmented Generation) pipeline.

## Planned Structure

```
knowledge_base/
├── cooperative_laws/       # Maharashtra Cooperative Societies Act, etc.
├── by_laws/                # Model by-laws and templates
├── schemes/                # Government schemes (PMFBY, KCC, etc.)
├── pacs/                   # PACS-specific documents
├── financial_literacy/     # Financial education content
└── grievance/              # Grievance procedures and contacts
```

## Status

🔜 Will be populated in Milestone 2 (RAG implementation).
